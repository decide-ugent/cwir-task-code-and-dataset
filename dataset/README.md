# CWIR task dataset

### Content
- ```behavioural_data/``` – Directory containinig behavioural experiment data 
- ```paradata/``` – Directory containing information regarding the amount of time each participant spent in each section of the instructions and the number of correct answers to the comprehension and attention checks, among other things.
- ```questionnaires_answers/``` – Directory containing the answers to the questionnaires
- ```stimuli/``` – Directory containing all the information about the gambles presented on each experiment (and practice) trial
